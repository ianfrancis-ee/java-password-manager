# java-password-manager
Object oriented Java application for secure password generation, validation, storage, and history tracking.
## Features

- Creates and stores passwords using file handling
- Validates passwords based on security requirements
- Prevents reuse of previous passwords
- Allows users to change existing passwords
- Generates random secure password suggestions

## Password Requirements

Passwords need to:
- Be between 6 and 10 characters
- Contain at least one uppercase letter
- Contain at least one lowercase letter
- Contain at least one number
- Contain at least one special character (`!@#$%^&*()`)

## Concepts included

- Object-oriented programming
- Java file I/O (`File`, `BufferedReader`, `BufferedWriter`)
- Exception handling
- ArrayLists
- String processing
- Random password generation
